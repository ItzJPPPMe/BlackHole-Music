# BlackHole Music

YouTube, Instagram, TikTok ve daha birçok platformdan video ve müzik indirmenizi sağlayan, masaüstünde çalışan bir indirici.

## Özellikler

- **ARAMA** — bağlantı yapıştır, çöz ve **indir**. Video (Mp4) veya ses (Mp3) olarak kaydet.
- **VİDEOLARIM / MÜZİKLERİM** — indirdiğin dosyalar listende biriksin; indirme klasörü otomatik taranır.
- **LİSTELERİM** — istediğin parçaları listelere ekle, tek listeden indir; YouTube playlist bağlantılarını da çözebilirsin.
- **Kalıcılık** — indirme geçmişin ve listelerin uygulama kapansa bile kayıtlı kalır.

## Kullanım

1. Programı aç.
2. ARAMA kutusuna video/müzik bağlantısını yapıştır (YouTube, Instagram, TikTok, ...).
3. **İndir** butonuna bas.
4. Dosyalar `C:\Video İndirici` klasörüne kaydedilir.

## Teknik

- **menü** — Electron masaüstü kabuğu (yt-dlp + ffmpeg yerleşik)
- **backend** — Rust (axum) yerel API sunucusu
- **frontend** — React + Vite arayüz
- İndirme motoru: yt-dlp; dönüştürme/birleştirme: ffmpeg
